# AI assistance and authorship disclosure

EverFront was developed by William Zhu with substantial AI assistance. Codex assisted with GDScript, UI implementation, source inspection, audio mapping and asset preparation. OpenAI imagegen generated or edited selected sprite atlases, icons, slash and warning effects, alpha cutouts and spacing corrections. The original project direction and subsequent selection/rejection decisions are documented in GDD.md, AGENTS.md and Git history. User supplied artwork and recordings are not automatically attributed to imagegen merely because their filenames resemble prompts.

The music workflow involved Suno prompt discussion and user supplied Chase Mode and Untitled files; exact final generation prompts, model, subscription at creation and fees remain unconfirmed. Several effects came from user supplied downloaded audio, not an AI synthesizer. The new source manifest records actual conversions and measured gains. No AI service runs in the game; no API key is required by the exported application. Runtime gameplay, local profiles and telemetry are not sent to an AI service.
